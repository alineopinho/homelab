# Homelab

Laboratório pessoal de infraestrutura e redes, desenvolvido para explorar conceitos de administração de sistemas, virtualização, serviços de rede, monitoramento e automação.

## 🎯 Objetivos

- Projetar uma infraestrutura virtualizada.
- Praticar administração de servidores Linux.
- Compreender a configuração e o funcionamento de serviços de rede.
- Explorar aplicações conteinerizadas com Docker.
- Implementar monitoramento e procedimentos de recuperação de incidentes.
- Documentar configurações, decisões técnicas e resultados dos testes.

## 🛠️ Tecnologias previstas

| Tecnologia | Finalidade |
|---|---|
| Linux Server | Administração de servidores |
| VirtualBox | Virtualização do ambiente |
| Docker | Execução de aplicações em contêineres |
| DNS | Resolução de nomes na rede local |
| Samba | Compartilhamento de arquivos |
| Uptime Kuma | Monitoramento de serviços |
| Bash | Automação de tarefas |
| draw.io | Diagramas de infraestrutura |

As tecnologias poderão ser ajustadas conforme os recursos disponíveis durante o desenvolvimento.

## 📋 Etapas do projeto

1. Planejamento e definição dos requisitos.
2. Modelagem da arquitetura e topologia de rede.
3. Configuração do ambiente virtualizado.
4. Implantação dos serviços de infraestrutura.
5. Configuração de aplicações em Docker.
6. Implementação do monitoramento.
7. Simulação e documentação de incidentes.
8. Automação e melhorias contínuas.

## 📌 Status

**Em desenvolvimento — Etapa 1: Planejamento e Arquitetura.**

O projeto está inicialmente concentrado na documentação e no desenho do ambiente. A implantação prática será realizada posteriormente em um ambiente autorizado e adequado.

A documentação técnica será adicionada progressivamente, incluindo requisitos, decisões de arquitetura, diagramas, configurações e runbooks de incidentes.
